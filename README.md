# Olá, seja bem vindo ao meu perfil, meu nome é Danilo Kroll!

Sou Danilo Kroll, profissional de tecnologia com atuação em Business Intelligence e Engenharia de Dados, focado no desenvolvimento de soluções que transformam dados em informações relevantes para o negócio.

Tenho experiência na construção de relatórios e indicadores, integração de diferentes fontes de dados, desenvolvimento de processos ETL/ELT e automação de rotinas.

Atualmente, trabalho principalmente com Microsoft Fabric, Power BI, SQL Server e Python, buscando desenvolver soluções eficientes, escaláveis e de fácil manutenção.
